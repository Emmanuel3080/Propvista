# 🏠 PropVista

**Appointment booking platform for real estate viewings.**

Buyers book property viewings with agents. Agents manage availability and bookings — all in one place.

## ✨ Overview

PropVista lets buyers browse listings and book a viewing appointment directly with an agent, while agents manage their availability and confirm bookings from a dashboard.

## 🚀 Features

- 📅 Book property viewing appointments in a few clicks
- 🏘️ Browse property listings with details and images
- 👤 Agent dashboard to manage availability & bookings
- 📧 Automated booking confirmation emails via Resend
- 🔐 Secure authentication for buyers and agents
- 📱 Fully responsive design

## 🛠️ Tech Stack

**MERN Stack** — MongoDB · Express.js · React.js · Node.js
**Email** — Resend

## ⚙️ Getting Started

\`\`\`bash
# Clone the repo
git clone https://github.com/Emmanuel3080/propvista.git


# Install dependencies
npm install



# Run the dev server
npm run dev
